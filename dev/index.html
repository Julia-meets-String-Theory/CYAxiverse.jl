CYAxiverse.jl

CYAxiverse.jl is an actively developed Julia package for computing axion and axion-like-particle (ALP) spectra from string-theory data. It reads geometry and potential data generated by CYTools and provides Julia workflows for spectra, vacua, inflation diagnostics, and publication plots.

The core package is Julia-only: Python, CYTools, Docker, and plotting packages are optional. Start with the installation guide, then use the User guide and Pipelines pages for data-backed workflows.

The package declares compatibility with Julia 1.12. Continuous integration currently tests Julia 1.12 on an Ubuntu x64 runner; other platforms may need additional local validation.

Quick start

CYAxiverse.jl is not registered in the Julia General registry. Install the development branch used by the current documentation with Julia 1.12:

using Pkg
Pkg.add(url = "https://github.com/Julia-meets-String-Theory/CYAxiverse.jl.git",
        rev = "vmm")

using CYAxiverse
CYAxiverse.greet_CYAxiverse()

The command above installs the core package. Data-backed pipelines and the optional CYTools/PyCall bridge have separate prerequisites described on the installation page. The public rev = "vmm" reference will be updated with the deployment configuration when the release branch transition is approved.

Citation

Cite the publication that matches the calculation being reported. The local axion–photon scan is based on arXiv:2309.13145, and the orientifolded database workflow uses the methods in arXiv:2412.12012. For the broader axion and ALP spectrum context, see Superradiance in String Theory.

CYAxiverse.jl does not currently publish preferred software-citation metadata. Until that metadata exists, cite the repository and the exact Git revision used for the result, including the commit SHA in addition to any branch name.
