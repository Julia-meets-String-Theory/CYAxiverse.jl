# CYAxiverse.jl Claude Code Instructions

Read and follow the repository instructions in `AGENTS.md` before planning or
carrying out work. Also read the supplemental standards in
`.copilot/AGENTS.md` and `.github/copilot-instructions.md`.

The release and versioning policy in `AGENTS.md` is normative. In particular,
feature branches record version impact, while the reviewed integration or
release boundary updates `Project.toml` with the appropriate SemVer bump.
