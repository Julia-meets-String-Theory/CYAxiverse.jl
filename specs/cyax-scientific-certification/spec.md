## 6. Scientific model and fixed proof methods

### 6.1 Exact model and interpretation

Inputs are Q in Z^(n×M), L in R^(2×M), K in R^(n×n), phases phi in R^M, and seed theta0 in R^n. Axions occupy Q rows and instantons its columns. Theta has period one in each component; phi is in radians. Default phases are exact zeros.

All inputs describe one precisely specified finite numerical model. Accept Integer (excluding Bool), Rational with integer components, Float16/32/64, and finite BigFloat values; Q entries must be integers. Recover each supplied value exactly before interval conversion. In particular, the Float64 literal 0.1 is its binary value, not the rational 1/10. Preserve supplied BigFloat values even if their source precision exceeds the working precision.

Reject complex, missing, nonfinite, uncertain-interval, and unsupported scalar inputs. Check n,M >= 1, shapes, finite values and exact symmetry of the effective indexed K matrix. Do not transpose Q by inference, average a nonsymmetric K, round charges to integers, or infer square-matrix orientation. A real Symmetric/Hermitian wrapper denotes its effective indexed matrix. The caller explicitly supplies the canonical orientation.

The model is

    V(theta) = sum_a A_a [1 - cos(2*pi*Q_a' theta + phi_a)]
    A_a = L[1,a] * 10^L[2,a]
    s = max_a L[2,a]
    Ahat_a = L[1,a] * 10^(L[2,a] - s)
    Vhat = 10^(-s) V.

Signed and exactly zero coefficients are valid. Evaluate every nonzero term, in input order; omit only contributions proved exactly zero. Never discard a term because of relative size or Float64 underflow.

The derivatives used for proof are

    F(theta) = 2*pi * sum_a Ahat_a Q_a sin(2*pi*Q_a' theta + phi_a)
    H(theta) = (2*pi)^2 * sum_a Ahat_a Q_a Q_a' cos(2*pi*Q_a' theta + phi_a).

Enclose pi as the mathematical constant. Enclose powers directly or as exp((L[2,a]-s)*log(10)), with guaranteed arithmetic throughout. Compute integer/rational differences exactly before enclosure. Explicitly construct exact constants and charges; do not insert approximate decimal constants or first evaluate powers/trigonometry in Float64.

Require every proof interval to be finite, nonempty, guaranteed and decorated com. An empty interval, NaI, an unguaranteed enclosure, division through zero or a weakened decoration cannot support a proof. Never repair such metadata by assigning a more favorable flag [R9].

The spectral claim is precisely

    H(theta*) v_i = lambda_i K v_i

for the scaled Hessian and supplied numerical K. Store s exactly. Certification establishes no physical mass in eV, geometry-exact metric, controlled compactification, moduli stabilization, or observational viability. A reader's prior numerical inversion error is outside this exact-input model. Every certificate carries these interpretation fields.


### 6.2 B: local-root theorem and representation

Use one unwrapped box X in R^n. Every coordinate width must be positive and strictly below one. Its projection to the period-one torus is injective, including when X crosses zero. Never apply modulo separately to interval endpoints.

Normalize an input seed by an exact integer translation once, recording that translation. Newton proposals thereafter remain in the lift. Displayed periodic coordinates are separate from proof coordinates. This single-root API does not count or merge solutions from different calls; overlapping boxes alone do not prove equality.

Let x0 be an exactly represented point in int(X) and C an exactly represented numerical approximate inverse of mid(H(X)). Treat C's finite entries as exact dyadic numbers; they need not be a verified inverse. Compute

    R(X) = I - C H(X)
    W(X) = x0 - C F(x0) + R(X) (X - x0)
    q = max_i sum_j sup(abs(R(X)[i,j])).

Accept only when every bound is validated, W(X) is strictly inside X in every coordinate, and the outward-rounded upper bound q < 1. Record both tests. The contraction maps X into itself; q < 1 also makes C H nonsingular, hence C nonsingular, so the unique fixed point solves F=0 [R10].

This theorem proves one locally unique stationary point and nonsingularity throughout the enclosure. It cannot certify a degenerate isolated root or an exact flat mode. Failed inclusion proves neither existence nor nonexistence. Do not add an exclusion theorem to v1.

Construct proposals using bounded BigFloat Newton steps and numerical linear solves. Their residuals and solver success are diagnostic only. A zero gradient, unchanged iterate, failed decrease or exhausted Newton budget stops numerical proposal refinement; the current finite center must still receive the scheduled interval proof attempts. Numerical convergence never substitutes for proof, and numerical nonconvergence never vetoes a valid proof. Singular proof preconditioners, rank-deficient active charge systems or failed inclusion yield explicit noncertification. An exact active-charge-rank shortcut is optional; the root proof itself remains mandatory.

### 6.3 Shared interval inertia kernel

For a symmetric interval matrix A, implement unpivoted scalar interval LDL:

    d_j = A[j,j] - sum_(k<j) ell[j,k]^2 d_k
    ell[i,j] = (A[i,j] - sum_(k<j) ell[i,k] ell[j,k] d_k) / d_j.

Use interval squaring, validated sums and divisions, and one common triangular representation. Proceed only if every pivot interval excludes zero. Successful pivot signs prove the inertia of every symmetric point matrix enclosed by A. All positive pivots prove K positive definite; the same kernel classifies H(X).

V1 uses the identity permutation and no interval 2×2 pivoting. A failed scalar pivot means the factorization is inconclusive; it does not prove singularity or indefiniteness. Test this explicitly on a nonsingular matrix with zero leading pivot.

For K, return INVALID_INPUT/METRIC_NOT_SPD only when non-positive-definiteness is actually demonstrated, for example by a nonpositive exact diagonal or a complete certified inertia with a negative direction. Otherwise a failed positivity proof is INCONCLUSIVE/METRIC_PD_UNPROVED.

Hessian classes are MINIMUM, MAXIMUM, SADDLE, or UNRESOLVED, separate from root status. MINIMUM requires all directions proved positive; MAXIMUM all negative; SADDLE at least one positive and one negative. Valid spectral sign counts may establish these classes if direct H inertia is inconclusive. Never label an unresolved direction a certified zero.

### 6.4 C: generalized spectrum

First prove K positive definite. Recompute H(X) over the entire certified root box; midpoint Hessians alone are insufficient.

**Structural diagonal shortcut.** If K and the complete H(X) enclosure have exact zero off-diagonals, enclose each ratio H[i,i]/K[i,i]. Obtain ordered bounds by sorting the lower endpoints and upper endpoints separately. Group overlapping ratio intervals into connected clusters; each component contains exactly its number of diagonal modes. This route must resolve T06 without subtracting order-one quantities to recover a tiny eigenvalue.

**General route.** At an exact dyadic trial t, run the inertia kernel on H(X)-tK. A successful negative count c(t) equals the number of generalized eigenvalues strictly below t for every enclosed symmetric Hessian. Only successful counts may update endpoints.

If c(a)=r and c(b)=s with a<b, the interval [a,b] contains precisely modes r+1 through s, counting algebraic multiplicity. Each of those ordered eigenvalues is enclosed. This is a cluster population claim, not proof that eigenvalues coincide.

Create the initial trial radius deterministically. Compute the numerical estimate

    B0 = max(1, opnorm(mid(H(X)),Inf) * opnorm(inv(mid(K)),Inf)).

Use matrix infinity operator norms. Set R to the smallest power of two at least B0; this is only a hint. Verify c(-R)=0 and c(R)=n, doubling R at most 32 times if necessary. A failed numerical estimate starts at R=1. No global bracket is certified until both endpoint counts pass.

Refine nonempty brackets in a FIFO queue, left child before right. Try the exact midpoint first; on failure try the first quarter, then the third quarter, stopping at the first successful count. Discard only subintervals whose certified count difference is zero. Detect rounded/repeated trial points. If all three trials fail, retain the existing certified cluster with an unresolved-refinement reason.

A sign-resolved interval [a,b] meets the default resolution target iff its width divided by min(abs(a),abs(b)) is at most 2^-20, verified with outward rounding. There is no global absolute tolerance floor. An interval crossing zero has unresolved sign and cannot satisfy this relative target.

Keep proved bounds and resolution status separate. Finite coarse certified bounds may survive a refinement limit; they cannot pass a gate demanding narrower individual bounds. A cluster may certify several modes without resolving their internal ordering or degeneracy. If no global bracket is proved, spectrum status is INCONCLUSIVE.

Do not use ordinary eigvals, an ordinary LDL/Cholesky, eigenbox, or a numerical residual as proof. IntervalLinearAlgebra's documented eigenbox is nonrigorous, and its verify_eigen treats eigenvalues as simple; neither is the general backend specified here [R11].

### 6.5 Arithmetic isolation: a required proof precondition

The proof kernel uses IntervalArithmetic 0.22.36 `Interval{BigFloat}` values as validated containers and a small local adapter for explicitly rounded operations. Pinned source inspection shows `configure(rounding=:none)` can replace ambient arithmetic entry points. Therefore `isguaranteed` and `com` alone cannot establish that those entry points are safe.

Implement the following fixed adapter in `intervals.jl`:

1. Use explicit BigFloat endpoint construction at the requested precision. Preserve exact integer/rational input values separately. Enclose a rational by downward/upward BigFloat bounds for its numerator and positive denominator, then the fixed directed division below. Never tolerance-rationalize a floating value. Enclose mathematical pi using the audited directed BigFloat irrational constructor, not an approximate floating pi literal.
2. Route scalar endpoint arithmetic through the pinned explicit methods `_add_round`, `_sub_round`, `_mul_round`, `_div_round` with `IntervalArithmetic.IntervalRounding{:correct}()` and explicit RoundDown/RoundUp. Audit the correspondingly parameterized `_sin_round`, `_cos_round`, `_exp_round`, `_log_round` and their actual BigFloat/CRlibm dispatch. These private backend calls are isolated in this one file and recorded in the source/environment profile.
3. Build interval addition/subtraction from directed endpoints; multiplication from the minima/maxima of all four directed endpoint products; reciprocal/division only when the denominator excludes zero. For true interval square, use lower bound zero when the interval crosses zero, otherwise the smaller downward endpoint square; use the larger upward endpoint square for the upper bound. Implement absolute value and maxima by endpoint comparisons. Use monotonic endpoint evaluation for exp/log, rejecting log inputs not strictly positive.
4. Enclose sine/cosine by directed evaluations at both endpoints plus all possibly attained extrema. With a guaranteed enclosure Π of mathematical pi, compute using only this adapter: `Jsin_max = X/(2Π)-1/4`, `Jsin_min = X/(2Π)+1/4`, `Jcos_max = X/(2Π)`, `Jcos_min = X/(2Π)-1/2`. Whenever `ceil(BigInt, inf(J)) <= floor(BigInt, sup(J))`, include the corresponding +1 or -1. Every true critical point maps to an integer in the conservative J enclosure; false-positive extrema only widen the result. Handle wide arguments conservatively; never use an ambient quadrant helper.
5. Construct each new Interval from the already proved finite ordered endpoints using the audited explicit BigFloat constructor. Require guaranteed/com on the constructed result. This construction records an enclosure established by the adapter; it must not upgrade a failed or unguaranteed pre-existing result's flags. Do not call ambient IA interval `+`, `-`, `*`, `/`, `^`, exp/log/sin/cos or generic interval matrix multiplication inside a proof.
6. Evaluate log powers as `exp((ell-s)*log(10))` through the adapter; form `ell-s` exactly first. Construct constants explicitly, including zero and one. Evaluate summations in term index order and matrix products with fixed scalar loops. Build each Hessian upper triangle once from exact charge products, then copy the identical interval to its symmetric entry. No floating-charge product, reassociation, threaded reduction, triangle averaging, fast-math or dependency-pruning threshold.

Backend qualification must check every primitive and constructor used by proof, not just a sentinel calculation. Include nonrepresentable rationals, signed products/divisions/squares, pi, log/exp identities with independent containment references, sine/cosine extrema and wide arguments, huge/small exponents, nonfinite/domain rejection and all metadata. Test false claims and positive certification after a deliberate `configure(rounding=:none, numtype=Float64, power=:fast, matmul=:fast)` in a disposable process. The certifier must still prove correctly and leave those ambient settings unchanged. If an audited private primitive cannot meet this requirement, stop at the backend boundary for a reviewed spec correction; do not fall back to ordinary IA operators.

Support serial use only in v1. Qualification/replay use `JULIA_NUM_THREADS=1`, one BLAS thread and no concurrent task mutating arithmetic state. Serialize the module's own proof entry points and scope nearest rounding for numerical proposals; restore prior BigFloat precision/rounding on success, noncertification and exception. Do not claim a local lock protects against unrelated concurrent BigFloat users. The fixed adapter must not call global IA configuration setters. Other dependency versions return typed `UNSUPPORTED/INTERVAL_BACKEND_VERSION` without evaluating unavailable backend symbols; core package import and legacy behavior stay available.

### 6.6 Deterministic proposal and proof schedule

For each exact input seed component define `z_i = floor(theta0_i + 1/2)` exactly and `u_i = theta0_i-z_i`, so `u_i ∈ [-1/2,1/2)`. Record original seed, z and u. This is the only periodic normalization. In particular, a stated root +1/2 is represented by -1/2 in this chosen lift; expected fixture positions are interpreted modulo the recorded integer translation, never by wrapping proof intervals.

At each precision restart from exact u, round once to a nearest dyadic numerical point, and perform one bounded Newton refinement for that precision. Use the infinity norm of the numerical scaled gradient for decrease; solve the numerical Hessian system with deterministic generic BigFloat LU, partial pivoting and the first lowest-index maximal-magnitude pivot on a tie. Try a full step, then up to eight halvings, accepting the first finite strict residual decrease. Singular solve, zero residual, unchanged iterate, no decrease or exhausted steps stops refinement and retains the last finite center. It does not suppress the proof attempts.

Reuse that center for every scheduled radius at this precision. Form exact rational X endpoints as the exact dyadic center ± exact radius. Recompute H(X) and C for each box; C is the finite nearest numerical inverse of mid(H(X)), solved with the same deterministic numerical convention. If a preconditioner cannot be formed, record that attempt's noncertification and continue. Every box has a new root proof; no box inherits a previous inclusion result. Numeric proposal failures are diagnostics, not mathematical exclusion.

|---|---|
| `precisions` | `(256,512)`; a nonempty strictly increasing subsequence of this pair |
| `max_newton_steps` | 20; integer 0–20 per precision, not per radius |
| `max_backtracks` | 8; integer 0–8 after the full step |
| `box_radii` | `(2^-20,2^-30,2^-40,2^-60)` exactly; 1–4 exact finite positive rationals, strictly decreasing and each <1/2 |
| `max_expansions` | 32 doublings after the first spectral radius; integer 0–32 |
| `max_inertia_evaluations` | 4096 per precision shared across all that precision's spectrum attempts; integer 0–4096 |
| `relative_width` | `1/1048576`; exact positive rational ≤ this value |
| `spectral_goal` | `clusters` by default; either `clusters` or `individuals` |
| `max_dimension`, `max_terms` | 32 and 2048; positive integers which may tighten, never increase, those ceilings |
| Required producer/replay pairs | 256→256 and 512→512 in fresh processes on every designated positive |
| Alternate replay precision | Explicit integer 2–4096; result is honestly VERIFIED/UNPROVEN/INVALID/UNSUPPORTED; does not replace required pairs |
| Watchdog | 300 s of warmed fixture computation per process, with installation/precompilation recorded separately |

Booleans are not numeric options. Reject wrong types, invalid ranges, empty/repeated schedules or invalid radii with ArgumentError. Options tighten work, domain or accuracy; they do not expand the qualified method. Default acceptance tests use the defaults with only the declared forced precision and spectral-goal overrides. Different thresholds/theorems/backends or higher qualification claims require reviewed changes.

Count every scalar-LDL invocation in the spectrum phase toward the spectral budget, including its K positivity and failed/successful shifted endpoint-count work. Direct H classification has at most one invocation per box in either the root-only or combined operation. Writer/replay revalidation is separate recorded verification work. A zero spectral budget leaves the spectrum unproved and cannot satisfy a positive gate. Retained already checked evidence may be reused within the same exact attempt only; never label a new matrix/trial as checked from a cached status.

The spectral queue preserves a certified frontier covering every mode. Refine each nonempty bracket until it is sign-resolved and its own relative width is met; for `individuals`, it must also have population one. Multi-mode brackets can terminate successfully only for the `clusters` goal. Try midpoint, then first quarter, then third quarter, stopping at the first successful count. Compute these dyadic trial values exactly as rationals; they need not be representable at the current working precision. Preserve original t when outward-enclosing it. A repeated endpoint/trial is a no-progress result. On failure of all trials or budget exhaustion retain the unsplit certified bracket/frontier with its unmet reason. Never drop an unrefined bracket or infer a zero mode.

For the diagonal route, store original coordinate ratio intervals, ordered lower/upper bounds and connected overlap components. Components have exact index populations; singleton requirements still apply to the `individuals` goal. Structural diagonal eligibility means exact zero off-diagonal entries of the whole interval Hessian and supplied K, not a numerical tolerance.

`certify_stationary_point` returns the first certified root box. `certify` attempts the spectrum for each certified box, proceeding to smaller boxes and then the next precision until the requested goal is met. A new box receives a new complete root proof. On exhaustion prefer complete certified spectral coverage, then a certified root, then diagnostic-only information; within the highest level retain the earliest attempt. Keep one complete internally consistent packet and list exhausted/unmet budgets separately. Never splice witnesses, Hessians, precisions or spectra from different attempts.

Wall-clock timeout is an observed incomplete run, reported as TIMEOUT in the runner evidence; it is not an inferred mathematical status or deterministic timing promise. Preserve completed immutable artifacts. Mandatory positives cannot pass through timeout, INCONCLUSIVE, UNSUPPORTED, UNAVAILABLE or skipped execution.

Reject wrong shapes with DimensionMismatch; invalid scalar/type, symmetry, or declared orientation contracts with ArgumentError. Do not infer a transpose. Finite-size/backend limits produce typed UNSUPPORTED certification results. A valid exact input too large for supported resource bounds is unsupported, not mathematically invalid. No lossy conversion is permitted to avoid a limit. Validate cheap dimensions/resource estimates before allocating a large proof object.

The call supplies Q in canonical axion-row orientation; square-matrix intent is not inferable and must be explicit in the call's documented contract. A real Symmetric/Hermitian wrapper denotes its indexed effective symmetric matrix, not ignored parent-array entries. Accept one-based AbstractArray inputs or reject unsupported indexing explicitly; never reinterpret indices. Preserve integer charge values before products. Expected numerical failure returns a typed outcome; unexpected programming errors propagate and fail the test.

CERTIFIED_BOUNDS requires finite certified coverage of all n modes. It does not imply individual separation, resolved signs, exact degeneracy or physical masses. Partial proved facts may be returned with spectrum INCONCLUSIVE and their exact scope. Hessian classification and root existence remain separately reported. K invalidity affects the metric/spectrum claim; a root proof for the potential is not invalidated merely because K is unsuitable.

The standalone spectrum call checks the input identity and replays the supplied root's exact witness before using it. A struct type, cached CERTIFIED status or a previous input digest is insufficient. It uses the supplied root's achieved precision only; require that precision to be included in options.precisions or throw ArgumentError. It never changes the box, runs Newton or silently combines a root and spectrum from different precisions. When `certify` retries a box it creates a new coherent root-and-spectrum attempt.

The writer accepts a RootResult or CertificationResult with a revalidated certified root, and rejects a noncertified result with ArgumentError. Revalidate EVERY emitted root, Hessian and spectrum claim against the model before exposing the final certificate; cached status flags are insufficient. It emits `kind="root_and_spectrum"` only with complete proved spectral coverage; otherwise it emits `kind="root"` and explicitly marks the absent spectral claim. A SpectrumResult alone does not supply writer authority or an implicitly recovered root; callers retain/use the corresponding CertificationResult. A required root-and-spectrum gate rejects root-only evidence. Writer resource overflow fails explicitly and atomically, without emitting a usable certificate or silently truncating values.

## 8. Exact evidence formats and replay contract

### 8.1 Common representation and parser boundary

Use `inputs.toml`, `certificate.toml`, and a separately generated `replay.toml`, with schemas `cyax-scientific-input-v1`, `cyax-scientific-certificate-v1`, `cyax-scientific-replay-v1`. These are scientific evidence formats, never authority/exchange state.

Every scientific scalar is a quoted reduced rational `numerator/denominator`: decimal integers, denominator positive, no leading plus/zeros, no negative zero, gcd one, zero only `0/1`. Integer Q values and translations require denominator one. Dyadic numerical witnesses require denominators that are powers of two. Recover binary floating values exactly; `Float64(0.1)` is not reinterpreted as 1/10. BigFloat values retain all original bits before working-precision enclosure. Do not serialize scientific scalars as TOML floating numbers or displayed BigFloat strings.

Define these reusable records; keys listed are the complete key set:

| Name | Exact record shape |
|---|---|
| `ExactArray` | `{dims = [integer dimensions], data = [rational strings]}`; column-major order, exact length product(dims), rank fixed by its field |
| `IntervalArray` | `{dims = [integer dimensions], data = [[lower rational, upper rational], ...]}`; same order and lengths; each lower ≤ upper |
| `SourceRef` | `{repository = string, commit = lower-case 40-hex string, tree = lower-case 40-hex string}` |
| `EnvironmentRef` | `{receipt_sha256 = lower-case 64-hex string, artifact_name = public-safe relative name}` |
| `CandidateProvenance` | Either `{status="unknown"}` or `{status="supplied", method=nonempty string, source_ref=nonempty public-safe string}` |
| `Interpretation` | `{basis="periodic_string", orientation="axions_by_terms", theta_period="1/1", phase_units="radian", coefficient_convention="signed_base10_log", numeric_semantics="exact_supplied_values", spectrum_convention="scaled_hessian_pencil", physical_normalization="not_established", s=rational}` |
| `Settings` | `precisions`, `max_newton_steps`, `max_backtracks`, `box_radii`, `max_expansions`, `max_inertia_evaluations`, `relative_width`, `spectral_goal`, `max_dimension`, `max_terms`, with exactly §6.6 types/ranges; scientific radii/relative width are rational strings |

Metadata dimensions/budgets/counts are TOML integers, not rationals; flags are actual booleans. Reject booleans where integers are required. Empty arrays are allowed only where this schema explicitly describes an empty collection.

Reject every unknown key at every nesting level, duplicate keys, wrong enum/type, missing required key, unknown schema version, nonfinite/float/date scientific values, malformed rationals, invalid counts, wrong lengths or asymmetric matrices. Do not silently normalize a malformed claim into a supported one. Validate sizes before allocating numerical arrays. No eval, include, external process command, network fetch, implicit private lookup or dereference of metadata locators originates from a certificate.

Supported representation limits: 16 MiB each for input/certificate/replay TOML, 4 MiB each for Skills case/receipt JSON, nesting depth ≤12, each rational integer component ≤4,096 decimal digits, each metadata string ≤4,096 UTF-8 bytes; scientific dimensions n≤32/M≤2048. Bound reads before parsing and bound nested-container handling. Exceeding a representation limit yields UNSUPPORTED/RESOURCE_LIMIT, not a mathematical invalidity claim. Array APIs may retain larger finite exact source values, but proof/writer conversion must detect resource overflow before expensive expansion and return unsupported or refuse output explicitly. No supported claim is emitted without its exact identity.

Hash exact file bytes with lower-case SHA-256, including all fields and final newline. A file never contains its own digest. The expected input/certificate identities come from a separately trusted manifest, not fields inside the untrusted payload. Integrity success does not authenticate an execution history.

### 8.2 Closed input schema

The complete `inputs.toml` top-level keys are:

```text
schema: "cyax-scientific-input-v1"
n: integer in 1..32
M: integer in 1..2048
Q: ExactArray, dims=[n,M], all denominators 1
L: ExactArray, dims=[2,M]
K: ExactArray, dims=[n,n], exact symmetry
phi: ExactArray, dims=[M]
interpretation: Interpretation
```

Default phi is the exact all-zero vector. Derive s as max(L's log row) and require exact equality to interpretation.s, including zero-coefficient terms. Q/L/K/phi describe precisely the supplied finite model; no inferred geometry or physical normalization is added.

### 8.3 Closed certificate schema

Complete top-level keys:

```text
schema: "cyax-scientific-certificate-v1"
kind: "root" | "root_and_spectrum"
input_sha256: lower-case 64-hex
source_ref: SourceRef
environment_ref: EnvironmentRef
settings: Settings
precision: 256 | 512, member of settings.precisions
candidate_provenance: CandidateProvenance
interpretation: Interpretation, exactly matching the input
root: RootEvidence
hessian: HessianEvidence
spectrum: AbsentSpectrum | SpectrumEvidence
```

`RootEvidence` has exactly:

```text
status="certified_root"
lift="unwrapped_centered_seed"
original_seed: ExactArray [n]
translation: ExactArray [n], integers
normalized_seed: ExactArray [n]
center: ExactArray [n], dyadic
box: IntervalArray [n]
preconditioner: ExactArray [n,n], dyadic
F_center: IntervalArray [n]
H_box: IntervalArray [n,n], exactly symmetric
W: IntervalArray [n]
q_upper: nonnegative rational
```

Require exact seed/translation identity and normalized seed in [-1/2,1/2), 0<box width<1, center in the original box interior, stored W strictly inside that original box, and q_upper<1. Root existence must be reproved from the actual input. No root record for an inconclusive result is a certificate.

`HessianEvidence` has exactly `classification` (MINIMUM/MAXIMUM/SADDLE/UNRESOLVED), `method` (direct_ldl/spectral_counts/none), `negative_count`, `positive_count`, `unresolved_count` (integers summing to n), and `pivots` (IntervalArray [n] for direct_ldl, otherwise [0]). A direct LDL proof has no unresolved pivots; a failed direct factorization supplies no invented signs. `none` requires UNRESOLVED and counts 0,0,n. `spectral_counts` requires the accompanying replayed spectral evidence. Every asserted count/class must follow from the reproduced proof. Zero modes are never inferred.

`AbsentSpectrum` has exactly `status="not_requested"` and `reason` in `{not_requested, coverage_unavailable}`. It is legal only for kind=root. An attempted but unavailable spectrum is explicitly absent as a proof claim. A root-only certificate may use only direct_ldl or none for HessianEvidence.method; partial spectral classification facts remain in diagnostics and cannot be serialized as a spectral_counts proof without accompanying complete SpectrumEvidence.

The discriminator is two-way: kind="root" requires AbsentSpectrum; kind="root_and_spectrum" requires SpectrumEvidence.

`SpectrumEvidence` has exactly:

```text
status="certified_bounds"
route: "diagonal" | "inertia_counts"
goal: "clusters" | "individuals", equal to settings.spectral_goal
metric_pivots: IntervalArray [n], all strictly positive
bounds: IntervalArray [n], ordered mode enclosures
clusters: array of Cluster records, nonempty, exact coverage 1:n
negative_count: integer 0..n
positive_count: integer 0..n
unresolved_count: integer 0..n, counts sum to n
resolution_met: boolean, derived from all claims and goal
reason: "goal_met" | "budget_exhausted" | "refinement_inconclusive" |
        "sign_unresolved" | "individuals_unresolved"
endpoint_counts: array of EndpointCount records
diagonal_ratios: IntervalArray [n] for diagonal route, otherwise [0]
```

`Cluster` has exactly `first`, `last`, `population` (positive integers, population=last-first+1), `lower`, `upper` (rationals, lower<upper), `sign` (negative/positive/unresolved), and `relative_width_met` (boolean). Clusters are sorted, cover 1:n without gaps or duplication, and contain their respective ordered bounds. An unresolved sign never meets relative resolution. `individuals` additionally requires every population=1.

Set reason=goal_met exactly when resolution_met=true. Otherwise choose the first applicable reason in this fixed order: budget_exhausted, refinement_inconclusive, sign_unresolved, individuals_unresolved. The reason records producer diagnostics; replay derives mathematical goal flags independently and does not authenticate execution/budget history from this string.

`EndpointCount` has exactly `trial` (dyadic rational), `negative` (integer 0..n), and `pivots` (IntervalArray [n], every pivot excludes zero). On the inertia route, endpoint_counts MUST equal exactly the increasingly sorted unique union of the final clusters' lower and upper endpoints, with one record per endpoint and no other successful or failed trial. Require length(endpoint_counts)<=2n (hence <=64), and validate exact set equality/cardinality after bounded structural parsing but before numerical factorisation. Every final cluster endpoint has its successful count: c(lower)=first-1 and c(upper)=last. For every mode i in that cluster, bounds[i] MUST equal its exact [lower,upper]; a narrower interval inside a proved cluster is not independently proved. Keep all intermediate search history, including unused successful trials, in detached diagnostics rather than this proof payload. Counts must be consistent/nondecreasing. On the diagonal route, endpoint_counts is empty; bounds MUST equal the separately sorted lower and upper endpoints of the revalidated submitted coordinate ratios, and clusters MUST follow their connected overlap populations. A caller may submit a wider honest ratio enclosure; all resulting bounds/clusters/flags must be updated consistently and reproved.

During ordinary development, materialize one valid serialized example of each kind after the writer first works, and include those literal format examples in the spec appendix before the final candidate freeze. Preserve their actual development producer identities and label them historical examples, excluded from final acceptance evidence. The final frozen candidate generates fresh acceptance examples in detached evidence. This avoids inserting later sample hashes into an already reviewed candidate. Sample formatting does not authorize additional keys or alter the schema.

### 8.4 Serialization and atomic writer

Use the pinned Julia TOML writer with sorted keys, UTF-8, LF and one final newline. Deterministic ordering extends to arrays of clusters/counts, fixed numeric summations and all immutable fields. Do not place timestamps, elapsed timings, absolute paths or machine/session details in input/certificate artifacts. Identical exact model, original seed, provenance, operation/kind, settings, source identity and environment identity must produce byte-identical immutable artifacts on the qualified serial profile. Different seeds or precisions may legitimately produce different certificates.

Use a fresh destination and exclusive ownership of its creation. Stage outputs in the same filesystem; close/validate the complete inputs before making the final certificate filename visible. Refuse an existing final destination and do not overwrite it. On ordinary failure no final certificate may be presented with a missing/partial bound input. Detect and reject a pre-existing/conflicting path. The consumer always checks the pair's externally bound identities. Do not claim crash durability beyond the tested filesystem guarantees.

### 8.5 Replay: prove the submitted proposition

The core checker must perform all of these obligations independently of producer/Newton control flow:

1. Read bounded exact input/certificate bytes, compare external expected hashes, then parse/validate the complete closed schemas and input interpretation. Recompute s and seed translation.
2. Retain original rational claims alongside outward working enclosures. Reconstruct the submitted X, center and C; check dimensions, finiteness, original positive widths<1, center containment and dyadic conditions. Do not replace a witness, run Newton or select another root.
3. Through the fixed adapter recompute F(center), H(X), R, W and q. Check that recomputed F/H/W and q fit the ORIGINAL stored rational claims. Check both recomputed strict inclusion and the stored W's strict inclusion against ORIGINAL X endpoints, and the stored/recomputed q upper bounds below one. Outward operands do not relax submitted claims.
4. Recompute each asserted Hessian/metric LDL pivot and its sign. The reproduced pivot enclosure must fit the original stored pivot enclosure. A failed replay factorization proves nothing and cannot be repaired by relabeling the stored class.
5. For the inertia route, first require the exact final-endpoint set and <=2n cardinality from §8.3, then recompute each exact submitted trial's shifted inertia and its stored pivot/count claim. Enclose the original dyadic trial as an operand if necessary; never replace it by a nearby rounded number. Check cluster endpoint counts, order, 1:n coverage, populations, signs and widths against original endpoints. For the diagonal route, re-establish exact structural zeros, positive K and original ratio/ordering/population claims. Midpoint eigvals is not evidence.
6. Derive the Hessian class and spectral status/goal flags; verify every asserted flag. At endpoints crossing zero, unresolved means unresolved, not a zero-mode certificate. Exact rational width comparisons are permitted and avoid adding rounding error.
7. Report exactly the submitted claims proved. A weaker true claim may verify yet fail a stricter fixture resolution gate. A valid certificate that cannot be proved at a different replay precision is UNPROVEN at that setting; its claims are never widened to force success.

Verification outcomes are VERIFIED, UNPROVEN, INVALID and UNSUPPORTED; CLI exit codes 0,1,2,3 respectively, and 4 for an unexpected internal error. Missing/unreadable files, bad integrity, malformed schema and inconsistent input contracts are INVALID. Failure to establish a well-formed numerical claim is UNPROVEN. An unsupported backend/resource profile is UNSUPPORTED. Required evidence demands VERIFIED, correct required kind and goal, and separately verified provenance.

The CLI requires explicit input and certificate paths and both expected digests; `--require` defaults to root_and_spectrum and `--precision` defaults to the submitted producer precision. Do not fetch defaults from private locations or the network. Its exact shape is:

```text
julia --startup-file=no --project=. scripts/verify_scientific_certificate.jl \
  --inputs INPUT --certificate CERTIFICATE \
  --expect-input-sha256 TRUSTED_INPUT_SHA256 \
  --expect-certificate-sha256 TRUSTED_CERTIFICATE_SHA256 \
  --require root_and_spectrum --precision 512
```

Capitalized arguments are bound from the trusted evidence index at execution; they are not evidence in this proposal. Reject unknown/repeated CLI arguments and unknown require selectors. The API may omit the expected certificate digest for exploratory mathematical checking, but formal evidence/CLI acceptance always supplies it externally.

### 8.6 Replay receipt and execution provenance

The core VerificationReport reports mathematical outcome and `provenance="NOT_CHECKED"`. Reading source_ref/environment_ref proves only their format, never their history. The existing authorized execution/review runner separately compares observed clean producer commit/tree and resolved environment with the trusted execution manifest and the certificate's references. It records the actual replay code/environment/precision and compares them to the approved replay profile. This is an observation by the runner, not an assertion copied from the file.

`replay.toml` has exactly:

```text

Missing/unreadable/malformed input before that boundary, resource failure before the header, or unexpected internal exit 4 remains ordinary detached command/error evidence; never fabricate producer references to fill a receipt.

The trusted external evidence index binds the receipt hash; the receipt does not hash itself. Mathematical VERIFIED and provenance PASS are both necessary for accepted scientific evidence. A 512-bit replay of a 256-bit witness, if performed, is an intentional separately recorded profile, not a claim that the producer ran at 512 bits. It is not a mandatory success gate in this v1 proposal. Required same-precision replay pairs remain mandatory.

Producer and replay may share the small audited arithmetic/derivative kernel. Disclose this shared trust: a separate process/CLI is not algorithmic independence. Independent analytic/exact-algebra oracles, adverse primitive tests and fresh scientific/code review supply additional evidence. This is validated numerical software, not a formally verified theorem prover.

### 9.3 False-claim tests must reach the proof logic

Run two distinct mutation modes. For integrity tests retain the original trusted digests. For semantic tests deliberately supply the digest of the mutated certificate while retaining the original trusted input identity, so a checksum rejection cannot masquerade as checking the false mathematics.

False semantic claims include a box excluding the root, x0 outside X, C=0, understated q, a falsely narrow Hessian enclosure, a spectral bound excluding the analytical eigenvalue, forged endpoint counts, and a saddle relabeled MINIMUM. Each must fail the relevant recomputed obligation. Include a deliberately too-narrow stored bound that would become wider if parsed at lower precision: replay must compare to its exact original endpoints and refuse the false claim.

Include a structural mutation that adds an unused otherwise well-formed EndpointCount to a valid inertia certificate and supplies its updated expected digest. Require INVALID for noncanonical endpoint-set membership before proof factorisation; correct minimal certificates still replay. This tests the new cheap structural obligation, not a false mathematical proposition.

Separate structural rejection from mathematical rejection. To test a false inertia-route endpoint, update the cluster endpoint, all affected mode bounds, the corresponding EndpointCount trial and redundant flags/counts consistently, leaving the document schema-valid; require failure of the actual shifted-inertia obligation. Count/class mutants likewise preserve unrelated structural invariants. Record which recomputed obligation rejected each semantic claim. An endpoint/bounds mismatch alone does not exercise the numerical proof checker.

Also test a mathematically valid weakening: widen a proved enclosure while updating its claim honestly. Replay may verify the weaker claim, while fixture-resolution acceptance can fail. The checker validates propositions; it does not reject every byte change as mathematically false.
