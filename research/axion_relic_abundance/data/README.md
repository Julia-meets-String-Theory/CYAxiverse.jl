# data/

`standardmodel2018.dat` is the table of the effective degrees of freedom g_*rho(T) and g_*s(T) of the Standard Model published by
K. Saikawa and S. Shirai, *Primordial gravitational waves, precisely: The role of thermodynamics in the Standard Model*,
JCAP 05 (2018) 035, arXiv:1803.01038. It is an ancillary file of that arXiv submission (version 2, 545,033 bytes, which is the size of
this file) and is also hosted by the authors at https://member.ipmu.jp/satoshi.shirai/EOS2018.php. Its header carries the citation.

- **Unchanged.** The file is a verbatim copy; its sha256 is pinned in `configs/methodology_v1.json` and checked by `tests/test_static.py`.
  Changing it would change every abundance.
- **Terms.** The authors state that the results are made available as tabulated data for use in other cosmological analyses; neither the
  arXiv page nor the ancillary-file listing names a separate license for the data, and the authors' page could not be retrieved
  automatically (HTTP 403). No redistribution restriction was found, but no explicit open license was found either.
  Please cite the paper above when using the table. If you redistribute this repository and need an explicit grant, ask the authors
  (contact address on their page); the table can also be downloaded from arXiv and compared by sha256 with the pinned value.
